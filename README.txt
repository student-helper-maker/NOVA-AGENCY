NOVA AGENCY WEBSITE - PRACTICE PROJECT

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted Digital-Agency-Website folder in VS Code.
3. Open index.html.
4. If you have Live Server installed, right-click index.html and choose "Open with Live Server".
   Alternatively, double-click index.html to open it in your browser.

PROJECT FILES
- index.html: page structure and content
- css/style.css: visual design and responsive layout
- js/script.js: mobile navigation and demo contact form

IMPORTANT
The contact form is front-end demo only. It does not send or store messages.
Before using this for a real client, connect the form to a secure backend or a trusted form service,
test it, and get the client's approval. Replace the sample brand, copy and portfolio concepts with
the client's real content and assets before delivery.
